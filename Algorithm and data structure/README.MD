Algorithms & Data Structures (AEDS I & II)

This repository contains a collection of algorithms and data structures implemented during the AEDS I (Algorithms and Data Structures I) and AEDS II (Algorithms and Data Structures II) subjects.

    [!IMPORTANT]
    This is an incomplete archive. Some implementations were unfortunately lost over time, but the core logic and most significant projects are preserved here.

These files are for academic and archival purposes. Since some files are missing, certain modules might refer to headers or functions that were part of the lost codebase.
